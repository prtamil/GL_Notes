## Level 3 — Random Variables ⭐⭐⭐⭐⭐

This is where AI begins.

Understand

```
Input
↓

Random Variable

↓

Output Number
```

Examples

```

## Level 4 — Expectation ⭐⭐⭐⭐⭐

Probably the most important concept in ML.

Instead of

"What happens?"

Probability asks

"What happens on average?"

Expected value.

Mean.

Average.

Loss.

Reward.

Everything in AI uses expectation.

---

## Level 5 — Variance ⭐⭐⭐⭐☆

Not average.

How much things vary.

This explains

- Noise
    
- Uncertainty
    
- Confidence
    
- Risk
    

---

## Level 6 — Distributions ⭐⭐⭐⭐⭐

This is huge.

Don't memorize formulas.

Instead understand

```
Distribution

=

Shape of uncertainty
```

Examples

```
Uniform

Normal

Bernoulli

Binomial

Poisson
```

Understand **why** each exists.

## Level 7 — Conditional Probability ⭐⭐⭐⭐⭐

This is the beginning of intelligence.

Instead of

"What is true?"

we ask

"What is true GIVEN I know something?"

Everything changes.

This becomes

Bayes

Naive Bayes

Hidden Markov Models

LLMs

Reasoning

Probably the most beautiful theorem.

Old Belief

+

Evidence

New Belief
```

That's all.
