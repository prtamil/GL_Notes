# Reading Guide

| Formula               | Read Naturally                         |
| --------------------- | -------------------------------------- |
| `P(A)`                | Probability of A                       |
| `P(A ∩ B)`            | Probability of A and B                 |
| `P(A ∪ B)`            | Probability of A or B                  |
| `P(Aᶜ)`               | Probability of not A                   |
| P(A\|B)               | Probability of A given B               |
| P(A \| B) = P(A)      | Knowing B doesn't change A             |
| `P(A ∩ B) = P(A)P(B)` | If independent, multiply probabilities |

---

## One final observation

By the end of today's session, you've learned that there are **three fundamental probability questions**:

1. **Single event**
    
    ```
    P(A)
    ```
    
    _"How likely is A?"_
    
2. **Conditional event**
    
    ```
    P(A | B)
    ```
    
    _"Knowing B happened, how likely is A?"_
    
3. **Joint event**
    
    ```
    P(A ∩ B)
    ```
    
    _"How likely are A and B to happen together?"_
    

One of the beautiful things about probability is that almost everything you'll learn next—multiplication rule, Bayes' theorem, random variables, and even machine learning probabilities—builds on these three questions. They are the core vocabulary of probability.
